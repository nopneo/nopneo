| 🚨 [**sepsis-bundle-hosxp**](https://github.com/nopneo/sepsis-bundle-hosxp) | ติดตาม **Sepsis Six Bundle** จาก HOSxP อัตโนมัติ — คำนวณการทำ bundle ครบภายใน 1 ชม. แจ้งเตือนเข้า LINE (MOPH Notify) และหน้าต่างเตือนสงสัย Sepsis ใน HOSxP |
